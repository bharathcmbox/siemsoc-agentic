# siemsoc-study

A personal study project covering SIEM (Security Information and Event Management) and SOC (Security Operations Center) concepts.

It is building toward an interactive, vendor-neutral **Agentic SOC simulator**. The simulator runs the same attack through different data architectures and SOC operating models, side by side.
